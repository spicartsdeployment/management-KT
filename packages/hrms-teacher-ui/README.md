# HRMS Teacher UI

Teacher module for School HRMS system.

## Features

- 17 comprehensive teacher pages
- Modern React with hooks
- SCSS styling (no Tailwind)
- Redux state management
- Real-time communication via Socket.io

## Installation

```bash
yarn install
```

## Development

```bash
yarn dev
```

## Build

```bash
yarn build
```

## Pages

1. Overview - Teacher dashboard
2. Meeting Schedules - Scheduled meetings
3. Resources Uploading - Upload teaching materials
4. Assignments & Exams - Manage assignments and exams
5. Student Evaluations - Grade and evaluate students
6. My Classes - View assigned classes
7. AI Assistant - AI-powered teaching assistant
8. Sports - Manage sports activities
9. Staff Requests - Submit staff requests
10. Community - Teacher community forum
11. Grievances - Report grievances
12. Staff Connect - Staff directory
13. Announcements - View announcements
14. Leave Management - Manage leave requests
15. Communication - Teacher chat
16. Day Schedules - View daily schedules
17. Attendance - Mark student attendance
